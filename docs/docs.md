# Dokumentacja lokalna

Ten dokument wyjaśnia, jak zbudować i przeglądać dokumentację MeshCore lokalnie.

## Budowanie i przeglądanie dokumentacji

```
pip install mkdocs
pip install mkdocs-material
```

- `mkdocs serve` - uruchamia serwer dokumentacji z automatycznym odświeżaniem.
- `mkdocs build` - buduje stronę dokumentacji.
